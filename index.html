How to Host This Website for FREE

Deploy this web app in under 2 minutes so you can access it anywhere.

1 Option A: GitHub Pages (Recommended & Easiest)

Save the code as index.html in a new GitHub repository, go to repository Settings > Pages, and select branch main. Your site will instantly go live at https://yourusername.github.io/repo-name!

2 Option B: Vercel or Netlify (Drag & Drop)

Simply drag and drop your HTML file onto Netlify Drop or import your repo into Vercel. Zero configuration needed!

3 About Steam API & CORS

Steam's Web API requires a personal API Key (free from Steam Community) and a CORS proxy if queried directly from a browser. This app includes a built-in Demo Library and manual entry so you can enjoy full functionality instantly without CORS blocks!
